Signature e-mail Rolling.

Chaque collaborateur remplit ses informations ci-dessous, choisit une signature et clique sur « Copier la signature », puis la colle dans sa messagerie. Les signatures sont faites pour les messageries : tableaux simples, styles écrits dans le code, police Arial (les polices de la charte ne s'affichent pas dans Gmail ou Outlook), logo hébergé sur le site.

Mon conseil : A pour tout le monde, D pour les réponses. A est sobre et lisible partout, même dans Outlook ; le lien « Réserver un échange » est le seul appel. B et C sont plus marquées (photo, bouton) : bien pour les commerciaux.

Gmail

  1. Cliquez sur « Copier la signature » ci-dessus.
  2. Gmail : roue dentée > Voir tous les paramètres > onglet Général > Signature > Créer.
  3. Collez (Ctrl + V ou Cmd + V) dans la zone, puis Enregistrer les modifications en bas de page.
  4. Choisissez-la dans « Paramètres par défaut des signatures » (nouveaux e-mails ; D pour les réponses).

Outlook (web et nouvel Outlook)

  1. Cliquez sur « Copier la signature ».
  2. Outlook : roue dentée > Comptes > Signatures > Nouvelle signature.
  3. Collez, nommez-la « Rolling », puis Enregistrer.
  4. Choisissez-la pour les nouveaux messages (et D pour les réponses / transferts).

Outlook sur ordinateur (Windows)

  1. Cliquez sur « Copier la signature ».
  2. Fichier > Options > Courrier > Signatures… > Nouveau.
  3. Collez dans la zone de modification, puis OK.
  4. La photo ronde (B) y reste carrée : c'est une limite d'Outlook.

Apple Mail

  1. Mail > Réglages > Signatures > +.
  2. Décochez « Toujours utiliser ma police par défaut ».
  3. Collez la signature dans la zone de droite.
  4. iPhone : Réglages > Mail > Signature n'accepte que du texte : utilisez D, ou envoyez-vous un e-mail avec la signature et copiez-la depuis l'e-mail reçu.

Le logo

Il est lu sur le site (…/themes/rolling/assets/medias/logo-rolling.png), il reste en place tant que le thème est installé. Pour plus de sûreté, importez-le dans Médias et collez sa nouvelle adresse dans « Adresse du logo ». Mode sombre : certaines messageries assombrissent le fond, le logo noir peut alors se lire moins bien (rien à faire côté signature).

Pour toute l'équipe d'un coup

Avec Google Workspace ou Microsoft 365, l'administrateur peut aussi poser la signature pour tout le monde (règles de signature de la console). Le bouton « Copier le code HTML » donne le code à coller dans ces outils ; il faut alors remplacer le nom, le poste et le téléphone par les variables de l'outil.
