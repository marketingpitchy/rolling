# Maquettes HTML (avant intégration au thème)

Sources sans images. Les images (photos, logos clients, captures) restent hors de git, dans le scratchpad
de la session ; `build.py <scratchpad>` les intègre et produit `maquettes-pages.html` (fichier ignoré par git).

- `logos-ecran/` : logos qui défilent + écran 00:05 interactif (validées).
- `pages/` : Offres, Réalisations, Réalisation, Témoignages, Témoignage, Blog, Article, Contact, Landing, 404.
  Les noms de classes sont ceux proposés pour Elementor (bouton « Voir les classes » dans la maquette).
