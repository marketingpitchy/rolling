Retours d'expérience (REX) : page Guides et fiches.

Un REX se crée comme un guide (lien vers votre page HubSpot), avec le thème « Retours d'expérience » et un nouveau champ « Témoignage lié ». Il apparaît alors à trois endroits, sans rien saisir de plus.

1. Le nom de la page

« Cas client » désigne déjà la page d'un témoignage avec récit (« Lire le cas client »). Pour éviter la confusion, je propose « Guides et retours d'expérience » (H1) et, dans le sous-menu Ressources, « Guides et REX » si vous voulez court. L'adresse /guides/ ne change pas.

2. Page Guides : le filtre « Retours d'expérience »

Le REX est une carte comme les autres. Sur l'image, la bande indique le type (« Retour d'expérience », champ « Type de document » déjà existant). Sans image, je propose le logo du client (repris du témoignage lié) sur un fond pêche et lilas. Sous la carte, un lien vers le témoignage.

3. Fiche témoignage : l'encart après le récit

Placé à la fin du récit, quand le lecteur est convaincu : couverture, type et nombre de pages, titre du REX, résumé, bouton. Avant « Les autres vidéos ». Absent si aucun REX n'est lié.

4. Fiche réalisation : une ligne sous la citation
