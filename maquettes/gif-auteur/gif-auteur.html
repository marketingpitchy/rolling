MAQUETTE · À VALIDER

GIF dans les articles et LinkedIn de l'auteur.

Deux ajouts pour les articles : un vrai composant pour les GIF Giphy (au lieu du bloc HTML qui s'affiche mal), et un lien LinkedIn dans la carte « Écrit par ». En bas : la réponse sur le nombre d'articles du blog.

01

Pourquoi le code Giphy s'affiche mal.

Le code d'intégration Giphy colle une petite page Giphy dans l'article (une iframe), pas un GIF.

Taille figée480 × 270 px ou un cadre en 56 % : le GIF ne prend pas la largeur du texte, ou garde des bandes vides s'il n'est pas en 16:9.
LourdLa page Giphy charge son lecteur, ses scripts et un GIF de plusieurs Mo. Ça ralentit l'article (et le score Google).
Cookies GiphyLe lecteur Giphy pose ses propres traceurs, hors de votre bandeau de cookies.
AccessibilitéPas de bouton pause, pas de texte pour les lecteurs d'écran, et le lien « via GIPHY » prend le style des liens de l'article.
02

Le composant GIF : trois looks.

Vous gardez votre habitude : coller le code Giphy dans un bloc « HTML personnalisé » (ou seulement le lien du GIF). Le thème le remplace par une vraie vidéo courte en boucle (la version légère du GIF fournie par Giphy), au bon format, avec un bouton pause. Les articles déjà publiés sont corrigés tout seuls.

A · Comme une image de l'article CONSEIL

Coins arrondis comme les images, format réel du GIF, bouton pause toujours visible en bas à droite. Légende facultative, crédit « via GIPHY » gardé, discret à droite.

Ordinateur · colonne de l'article

Une vidéo de 90 secondes résume mieux un rapport annuel qu'un PDF de 40 pages. Et vos équipes la regardent jusqu'au bout.

C'est tout l'intérêt du content repurposing : partir de ce qui existe déjà.

Comment l'ajouterBloc « HTML personnalisé » + code Giphy, comme aujourd'hui. Ou une composition « Rolling : GIF » (outil d'insertion, catégorie Rolling) avec une ligne pour le lien et une pour la légende.
Texte pour Google et les lecteurs d'écranRepris du titre du GIF chez Giphy (ex. giphy.com/gifs/happy-applause-… ⇒ « Happy applause »), remplaçable par la légende.
« Réduire les animations »Le GIF reste sur sa première image, avec un bouton lecture à la place du bouton pause. Rien ne bouge dans l'éditeur.
